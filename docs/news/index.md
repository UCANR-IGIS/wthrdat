# Changelog

## Changes in version 0.2.0 (2026-04-03)

- small modification to error message returned by
  [`wd_getdata_syn()`](https://ucanr-igis.github.io/wthrdat/reference/wd_getdata_syn.md)
  when no data is returned

## Changes in version 0.1.9 (2026-03-31)

- improved error messages returned by
  [`wd_getdata_syn()`](https://ucanr-igis.github.io/wthrdat/reference/wd_getdata_syn.md)
  and
  [`wd_getdata_wwg()`](https://ucanr-igis.github.io/wthrdat/reference/wd_getdata_wwg.md)

- added
  [`wd_getdata_checks()`](https://ucanr-igis.github.io/wthrdat/reference/wd_getdata_checks.md),
  an internal function used to check the arguments passed to
  `wd_getdata*()`

## Changes in version 0.1.8 (2025-10-28)

- modified
  [`wd_getdata_syn()`](https://ucanr-igis.github.io/wthrdat/reference/wd_getdata_syn.md)
  to convert NULL values returned by the API to NAs

## wthrdat 0.0.0.9000

- Initial version
