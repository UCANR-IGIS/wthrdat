# Changelog

## Changes in version 0.1.9 (2026-03-31)

- improved error messages returned by
  [`wd_getdata_syn()`](../reference/wd_getdata_syn.md) and
  [`wd_getdata_wwg()`](../reference/wd_getdata_wwg.md) when errors occur

- added [`wd_getdata_checks()`](../reference/wd_getdata_checks.md), an
  internal function used to check the arguments passed to
  `wd_getdata*()`

## Changes in version 0.1.8 (2025-10-28)

- modified [`wd_getdata_syn()`](../reference/wd_getdata_syn.md) to
  convert NULL values returned by the API to NAs

## wthrdat 0.0.0.9000

- Initial version
